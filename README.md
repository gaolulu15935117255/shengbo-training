# 圣博培训

面向育儿嫂、保姆的技能培训微信小程序。提供课程学习、岗位分类与学习进度入口。

## 本地运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录指向本仓库
3. AppID 可先使用测试号，之后在 `project.config.json` 中替换为正式 AppID

## 目录

```
pages/          页面
  index/        首页
  courses/      课程列表
  course-detail/课程详情
  mine/         个人中心
data/           本地课程数据
utils/          工具方法
```

## 功能规划

- 育儿嫂、保姆岗位培训课程
- 婴幼儿护理、辅食营养、安全急救等专题
- 学习进度与收藏（后续可接后端）
