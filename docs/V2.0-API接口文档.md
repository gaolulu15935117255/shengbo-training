## 1. 通用约定

### 1.1 协议与格式

- 协议：HTTPS
- 数据格式：`application/json; charset=utf-8`
- 时间格式：ISO 8601，`2026-08-20T12:00:00+08:00`
- 金额：接口层使用 **分**（整数），前端展示转为元

### 1.2 认证方式

小程序端登录后，请求头携带：

```
Authorization: Bearer <token>
```

后台管理端：

```
Authorization: Bearer <admin_token>
```

无需认证的接口在文档中标注 **【公开】**。

### 1.3 统一响应结构

**成功**：

```json
{
  "code": 0,
  "message": "ok",
  "data": { }
}
```

**失败**：

```json
{
  "code": 40001,
  "message": "参数错误：productId 不能为空",
  "data": null
}
```

**分页**：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 100,
      "totalPages": 5
    }
  }
}
```

### 1.4 业务错误码

| code | 说明 |
|------|------|
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40100 | 未登录或 token 失效 |
| 40300 | 无权限访问该资源 |
| 40400 | 资源不存在 |
| 40900 | 业务冲突（如重复支付） |
| 50000 | 服务器内部错误 |
| 60001 | 微信登录 code 无效 |
| 60002 | 微信支付下单失败 |
| 60003 | 订单状态不允许操作 |

### 1.5 分页参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| page | int | 1 | 页码，从 1 开始 |
| pageSize | int | 20 | 每页条数，最大 100 |

## 2. 认证模块 `/api/auth`

### 2.1 微信登录 【公开】

**POST** `/api/auth/login`

**描述**：小程序 `wx.login` 的 code 换取 token，首次登录自动注册。

**请求体**：

```json
{
  "code": "081abcXYZ",
  "nickName": "张三",
  "avatarUrl": "https://thirdwx.qlogo.cn/..."
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | wx.login 返回 |
| nickName | string | 否 | getUserProfile 昵称 |
| avatarUrl | string | 否 | 头像 URL |

**响应 data**：

```json
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "expiresIn": 2592000,
  "user": {
    "id": 10001,
    "nickName": "张三",
    "avatarUrl": "https://...",
    "membershipLabel": "普通用户",
    "membershipExpire": null
  }
}
```

## 9. 小程序对接示例

### 9.1 封装请求

```javascript
const BASE_URL = "https://api.example.com"

function request(options) {
  const token = wx.getStorageSync("token")
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + options.url,
      method: options.method || "GET",
      data: options.data,
      header: {
        "Content-Type": "application/json",
        Authorization: token ? `Bearer ${token}` : ""
      },
      success(res) {
        if (res.data.code === 0) resolve(res.data.data)
        else if (res.data.code === 40100) {
          wx.removeStorageSync("token")
          reject(res.data)
        } else reject(res.data)
      },
      fail: reject
    })
  })
}
```

### 9.2 登录

```javascript
wx.login({
  success(loginRes) {
    wx.getUserProfile({
      desc: "用于展示学员昵称和头像",
      success(profileRes) {
        request({
          url: "/api/auth/login",
          method: "POST",
          data: {
            code: loginRes.code,
            nickName: profileRes.userInfo.nickName,
            avatarUrl: profileRes.userInfo.avatarUrl
          }
        }).then((data) => {
          wx.setStorageSync("token", data.token)
        })
      }
    })
  }
})
```

### 9.3 支付

```javascript
// 1. 创建订单
const order = await request({
  url: "/api/orders/create",
  method: "POST",
  data: { productCode: "p5" }
})

// 2. 获取支付参数
const payParams = await request({
  url: "/api/pay/prepay",
  method: "POST",
  data: { orderNo: order.orderNo }
})

// 3. 调起支付
wx.requestPayment({
  ...payParams,
  success: async () => {
    const status = await request({ url: `/api/orders/${order.orderNo}/status` })
    if (status.status === "paid") {
      wx.showToast({ title: "购买成功", icon: "success" })
    }
  }
})
```
