## 启动步骤（用户醒来后可执行）

```bash
# 后端
cd backend
npm install
npm run init-db
npm run seed-questions
npm start

# 管理后台（另开终端）
cd admin
npm install
npm run dev
```

浏览器打开 http://localhost:5173 ，使用 admin / admin123 登录。
