**助手处理结果**：

- 说明 PRD 核心逻辑：权限控制、模拟支付、刷题流程
- 提供架构图与用户购买刷题完整流程说明

**讲解要点摘要**：

| 层级 | 路径 | 作用 |
|------|------|------|
| 全局入口 | `app.js` | 启动时恢复用户/学习/购买状态 |
| 数据层 | `data/*.js` | 品牌、课程、题库、商品 mock 数据 |
| 工具层 | `utils/` | 存储、登录、权限、订单、刷题逻辑 |
| 页面层 | `pages/` | 17 个页面，四大 Tab + 子页面 |
| 组件 | `components/tab-bar/` | 底部导航 |

**核心业务链路**：
1. **权限**：`permission.js` 判断免费 / 会员 / 已购商品 → 决定能否访问课程/题库
2. **刷题**：`quiz-practice.js` 按模式取题 → 答题判分 → 错题/收藏/记录
3. **购买**：`shop-detail.js` → `mockPay()` → `grantProduct()` 自动开通权限

**当前局限**：无后端、模拟支付、数据存本地；后续可接 API 与真实微信支付。
