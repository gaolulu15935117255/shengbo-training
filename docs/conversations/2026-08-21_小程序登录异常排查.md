## 对话 1

**时间**：2026-08-21 19:46

**用户**：
> 现在小程序的登录异常，排查问题并修复

**助手处理结果**：
- 线上 `POST /api/auth/login` 能签发 JWT（约 203 字符），但 `GET /api/auth/profile` 立刻 401
- 根因：`user_sessions.token` 为 `VARCHAR(128)`，JWT 被截断，登录成功后拉资料失败并清掉 token，表现为「登录成功又退出」
- 次因：登录强依赖已废弃的 `wx.getUserProfile`（且在 `wx.login` 回调里调用，丢失点击手势）
- 次因：后端用 `code` 哈希冒充 openid，每次 `wx.login` 都是新用户

**产出 / 变更**：
- `backend/src/routes/api/auth.js`：微信 code2session；session 存 token 的 sha256
- `backend/src/utils/wechat.js`：新增
- `backend/src/utils/jwt.js`：`hashToken`
- `backend/src/middleware/auth.js`：按 hash / 原文查找 session
- `backend/sql/schema.sql`、`patch_user_sessions_token.sql`：token 加宽到 512
- `backend/.env.example`：`WECHAT_APPID` / `WECHAT_APP_SECRET`
- `utils/auth.js`：登录只走 `wx.login` + 后端
- `pages/mine/*`：退出改为独立按钮；失败展示真实原因
- `utils/request.js`：`/api/auth/*` 401 不再按游客重试
