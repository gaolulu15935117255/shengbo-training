## 1. 项目结构

```
shengbo-training/
├── backend/          # Node.js Express API（端口 3088）
├── admin/            # Vue 3 管理后台（开发 5173，构建 dist）
├── data/             # V1.0 小程序本地 mock 数据
└── pages/            # 微信小程序前端
```

## 2. 环境要求

| 组件 | 版本 |
|------|------|
| Node.js | ≥ 18 |
| MySQL | 8.0+ |

---

## 3. 数据库初始化

### 3.1 配置环境变量

```bash
cd backend
cp .env.example .env
```

编辑 `.env`，填入 MySQL 连接信息（**勿提交 Git**）：

```env
DB_HOST=182.92.219.39
DB_PORT=3306
DB_USER=train
DB_PASSWORD=你的密码
DB_NAME=shengbo_training

JWT_SECRET=随机长字符串
ADMIN_JWT_SECRET=另一个随机长字符串
ADMIN_STATIC_DIR=../admin/dist
```

### 3.2 建表与种子数据

```bash
npm install
npm run init-db        # 执行 schema.sql + seed.sql，创建 admin/admin123
npm run seed-questions # 从 ../data/questions.js 导入 300 道题目
```

---

## 4. 启动后端 API

```bash
cd backend
npm start
# 或开发热重载：npm run dev
```

验证：浏览器访问 `http://localhost:3088/health`

---

## 5. 启动管理后台

### 开发模式（推荐联调）

```bash
cd admin
npm install
npm run dev
```

访问 `http://localhost:5173`，API 自动代理到 `http://localhost:3088`。

### 生产模式（与 API 同域部署）

```bash
cd admin
npm run build        # 输出 admin/dist

cd ../backend
# .env 中设置 ADMIN_STATIC_DIR=../admin/dist
npm start
```

访问 `http://localhost:3088` 即为管理后台。

## 7. 管理后台功能

| 模块 | 功能 |
|------|------|
| 仪表盘 | 用户/题目/订单/商品统计 |
| 题库管理 | 题目 CRUD、批量上下架 |
| 题库导入 | Excel/TXT 预览 → 确认入库 |
| 商品管理 | 虚拟商品 CRUD、上下架、权益配置 |
| 订单管理 | 订单列表、详情、退款（stub） |
| 用户管理 | 用户列表、详情、手动开通权益 |

---

## 8. 题库导入 Excel 模板

| 列名 | 必填 | 说明 |
|------|------|------|
| 题型 | 是 | 单选/多选/判断 或 single/multiple/judge |
| 题干 | 是 | 题目内容 |
| 选项A~D | 判断可留空 | 选项文字 |
| 答案 | 是 | 单选：A/B/C/D 或 0/1/2/3；多选：A,C；判断：正确/错误 |
| 解析 | 否 | 答案解析 |
| 知识点 | 否 | 如「新生儿护理·睡眠」 |
| 子章节 | 否 | 如「新生儿护理」，不填则用导入时选择的默认子章节 |

## 9. API 路径速查

| 端 | 前缀 | 认证 |
|----|------|------|
| 小程序 | `/api/auth`、`/api/quiz`、`/api/products`… | Bearer user token |
| 管理后台 | `/api/admin/*` | Bearer admin token |
| 管理员登录 | `POST /api/admin/auth/login` | 公开 |

完整接口见 [V2.0-API接口文档.md](./V2.0-API接口文档.md) 第 8 节。
