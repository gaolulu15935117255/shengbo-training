## 2. V1.0 现状简述（已实现）

### 2.1 产品定位

面向育儿嫂、居家保姆及意向从业者的 **线上培训 · 刷题 · 付费** 微信小程序。

### 2.2 已实现主要功能

| 模块 | 功能要点 |
|------|----------|
| **首页** | Banner 轮播、学员数据展示、公告、培训品类入口、品牌介绍、热门商品/课程推荐、联系方式 |
| **题库刷题** | 育儿嫂/保姆分类；章节练习、专项刷题、模拟考试；单选/多选/判断；错题本、收藏、答题记录；免费/付费权限控制 |
| **虚拟商城** | 专项课、全科班、会员套餐、冲刺题库包；商品详情；**模拟支付**；订单列表 |
| **课程学习** | 课程列表与详情、大纲与课时、学习标记、付费解锁 |
| **个人中心** | 微信授权登录（昵称/头像）、会员展示、学习统计、消息通知、关于我们 |

### 2.3 当前技术实现

```
微信小程序（前端）
  ├── data/*.js          → 静态 mock 数据（课程、题库、商品、品牌）
  └── wx.storage         → 本地缓存（用户、会员、订单、错题、收藏、刷题记录）
```

### 2.4 现状局限（V2.0 需解决）

| 问题 | 影响 |
|------|------|
| 数据存于手机本地 | 换机、清缓存后会员与学习数据丢失 |
| 未绑定微信 openid | 数据与用户账号无关，无法多端同步 |
| 模拟支付 | 无法真实收款，订单无法律效力 |
| 题库写死在代码里 | 无法后台增删改，无法批量导入 |
| 无后台管理系统 | 运营无法自助维护内容 |

## 3. V2.0 建设目标

1. **用户数据云端化**：以微信 openid 为唯一标识，会员、订单、刷题进度跨设备同步。  
2. **真实微信支付**：替换模拟支付，支付成功后自动开通权限。  
3. **题库可运营**：后台支持 Word/Excel/TXT 文档导入及手动维护，小程序端动态拉取。  
4. **保留 V1.0 前端体验**：在现有页面结构上对接 API，尽量减少 UI 改版。

## 5. 功能需求

### 5.1 用户登录与数据绑定

#### 5.1.1 需求描述

用户通过微信登录后，所有业务数据与 **openid** 绑定并存储在服务端，换机登录可恢复。

#### 5.1.2 登录流程

```
用户点击「微信授权登录」
  → 小程序 wx.login() 获取 code
  → 小程序 wx.getUserProfile() 获取昵称、头像（可选）
  → 请求 POST /api/auth/login { code, nickName, avatarUrl }
  → 后端 code 换 openid，创建/更新用户，返回 token
  → 小程序存储 token，后续请求携带 Authorization
```

#### 5.1.3 需云端绑定的数据

| 数据类型 | 现状存储 | 目标存储 | 说明 |
|----------|----------|----------|------|
| 用户基本信息 | 本地 sb_user | users 表 | openid、昵称、头像 |
| 会员信息 | 本地 sb_membership | user_memberships 表 | 等级、有效期 |
| 已购商品 | 本地 sb_purchased | user_entitlements 表 | 课程/题库权限 |
| 订单 | 本地 sb_orders | orders 表 | 支付状态、金额 |
| 错题本 | 本地 sb_wrong | user_wrong_questions 表 | 题目 ID 列表 |
| 收藏题目 | 本地 sb_favorite | user_favorites 表 | 题目 ID 列表 |
| 答题记录 | 本地 sb_records | quiz_records 表 | 模式、得分、用时 |
| 学习统计 | 本地 sb_quiz_stats | user_stats 表 | 刷题量、正确率等 |
| 已学课程 | 本地 learnedIds | user_courses 表 | 课程 ID、进度 |

#### 5.1.4 功能要求

- **F-USER-01**：登录成功后，服务端返回 JWT 或 session token，有效期可配置（建议 7~30 天）。  
- **F-USER-02**：小程序启动时携带 token 自动登录；token 失效引导重新授权。  
- **F-USER-03**：首次登录自动注册；再次登录更新昵称/头像。  
- **F-USER-04**：退出登录仅清除本地 token，服务端数据保留。  
- **F-USER-05**：换设备登录同一微信账号，会员、错题、收藏、刷题记录完整恢复。  
- **F-USER-06**：本地缓存作为离线兜底可选；有网时以服务端数据为准（需定义冲突策略：服务端优先）。

#### 5.1.5 验收标准

- 用户在 A 手机购买会员并刷题，B 手机登录同一微信可看到相同会员状态与错题。  
- 清除小程序缓存后重新登录，数据从服务端恢复。

### 5.2 微信支付

#### 5.2.1 需求描述

将现有「模拟支付」替换为 **微信小程序支付（JSAPI）**，支付成功后自动开通对应课程/会员/题库权限。

#### 5.2.2 支付流程

```
用户点击「立即购买」
  → POST /api/orders/create { productId }
  → 后端创建待支付订单，调用微信统一下单 API
  → 返回支付参数 { timeStamp, nonceStr, package, signType, paySign }
  → 小程序 wx.requestPayment(...)
  → 用户完成支付
  → 微信异步通知 POST /api/pay/notify（后端验签）
  → 后端更新订单状态为已支付，开通 user_entitlements
  → 小程序轮询或 WebSocket 确认支付结果，刷新权限
```

#### 5.2.3 功能要求

- **F-PAY-01**：支持购买虚拟商品：专项课程、全科班、会员套餐、冲刺题库包（与 V1.0 商品类型一致）。  
- **F-PAY-02**：订单号全局唯一，格式建议：`SB{yyyyMMdd}{序列号}`。  
- **F-PAY-03**：支付超时（建议 30 分钟）自动关闭待支付订单。  
- **F-PAY-04**：支付成功后 **自动开通权限**，无需人工审核（与 V1.0 业务规则一致）。  
- **F-PAY-05**：会员类商品按购买时长累加有效期；终身会员 expire_at 为空或固定标识。  
- **F-PAY-06**：订单列表展示：待支付、已支付、已关闭、已退款。  
- **F-PAY-07**：支持虚拟商品退款（后台可配置退款窗口，如 7 天内），退款后回收对应权限。  
- **F-PAY-08**：支付失败、取消支付给出明确提示，订单保持待支付可重新支付。

#### 5.2.4 前置条件（需客户/运营提供）

| 项 | 说明 |
|----|------|
| 微信小程序 AppID | 已认证的小程序 |
| 微信商户号 mchid | 开通 JSAPI 支付 |
| API 密钥 / 证书 | 服务端调用微信支付 V3 API |
| 支付回调域名 | 已备案 HTTPS 域名 |

#### 5.2.5 验收标准

- 真机完成 0.01 元测试支付，订单状态变为已支付，对应题库/课程即时解锁。  
- 支付回调重复通知时幂等处理，不重复开通权限。

### 5.3 题库导入与管理

#### 5.3.1 需求描述

运营人员在 **后台管理系统** 中导入题库文档或手动维护题目，小程序从 API 动态获取，不再依赖 `data/questions.js`。

#### 5.3.2 题库数据结构（与 V1.0 对齐）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 题目唯一 ID |
| category | enum | nanny / housekeeper |
| subcategory | string | 子章节 ID |
| type | enum | single / multiple / judge |
| stem | text | 题干 |
| options | json | 选项数组 |
| answer | json | 正确答案索引数组 |
| analysis | text | 解析 |
| knowledge | string | 知识点标签 |
| is_free | boolean | 是否免费 |
| status | enum | draft / published / offline |

#### 5.3.3 文档导入功能（核心）

- **F-QUIZ-01**：支持上传 **Word（.docx）、Excel（.xlsx）、TXT** 格式题库文件。  
- **F-QUIZ-02**：系统自动解析题型、题干、选项、答案、解析（可配置导入模板）。  
- **F-QUIZ-03**：导入前 **预览识别结果**，支持人工修正后再确认入库。  
- **F-QUIZ-04**：批量导入时可指定：所属大类（育儿嫂/保姆）、子章节、是否免费、是否付费题库。  
- **F-QUIZ-05**：导入失败给出行号与错误原因，支持部分成功。  
- **F-QUIZ-06**：支持题目手动新增、编辑、删除、批量上下架。  
- **F-QUIZ-07**：支持题库分类管理：大类、子章节的新增、排序、删除。

#### 5.3.4 建议 Excel 导入模板格式

| 列 | 必填 | 示例 |
|----|------|------|
| 题型 | 是 | 单选 / 多选 / 判断 |
| 题干 | 是 | 新生儿每天睡眠时间大约是多少？ |
| 选项A~F | 部分 | 8-10小时 |
| 答案 | 是 | C 或 A,C（多选） |
| 解析 | 否 | 新生儿每天睡眠约16-18小时… |
| 知识点 | 否 | 新生儿护理·睡眠 |
| 子章节 | 是 | 新生儿护理 |
| 是否免费 | 否 | 是/否 |

#### 5.3.5 小程序端改造要求

- **F-QUIZ-08**：题库分类、题目列表、单题详情改由 API 获取，支持分页（建议每页 20 题）。  
- **F-QUIZ-09**：刷题过程中答题结果实时或批量同步服务端。  
- **F-QUIZ-10**：权限判断以后端为准（是否已购/是否会员/题目是否免费）。  
- **F-QUIZ-11**：题目内容与答案 **不下发至前端缓存明文批量存储**（防泄题，可逐题拉取）。

#### 5.3.6 验收标准

- 后台上传 100 道 Excel 题目，5 分钟内可在小程序对应章节刷到。  
- 下架题目后小程序不可再刷到。  
- 导入预览可修正识别错误后再发布。
